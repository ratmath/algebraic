An exact calculator for everything in the library. Type an expression and press Enter (Shift+Enter for a new line). Numbers are exact, x makes polynomials, and name = … keeps a value for later lines.

Click an entry to edit it again.
How to write things

Fractions and decimals are exact: 0.1 is 1/10. Powers with a fractional exponent are principal roots: (-8)^(1/3), i^(1/2). Multiplication can be implicit: 2x^3, 3i, 2sqrt(2). Polynomials use x: roots(x^3 - 2). Pass digits to recognize in quotes to keep every digit.
