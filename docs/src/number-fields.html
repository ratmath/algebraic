Number fields

Q(√2) is every number a + b√2 with rational a and b. Sums, products and quotients stay in that form, so arithmetic is just arithmetic on pairs of fractions. A number field Q(α) does the same for any algebraic α, and it is far cheaper than general algebraic arithmetic when all your numbers live in one field.

Polynomials modulo m

If m is the minimal polynomial of α, of degree n, then Q(α) = Q[x]/(m): every element is a polynomial in α of degree below n, and multiplication is polynomial multiplication followed by reduction modulo m (using m(α) = 0 to rewrite αⁿ). Inverses come from the extended Euclidean algorithm: since m is irreducible, any nonzero g has s·g + t·m = 1, so s is 1/g. Nothing here grows beyond n coefficients, unlike resultant arithmetic, whose degrees multiply.

Compute in a field

Norm and trace

Multiplying by an element g is a linear map on the basis 1, α, …, α^(n−1). Its determinant is the norm N(g) and its trace is the trace Tr(g); both are rational, and they equal the product and the sum of the n conjugates of g. In Q(√d), N(a + b√d) = a² − db², and N(g·h) = N(g)·N(h). The units of the ring of integers are exactly the integral elements of norm ±1; the continued fraction page finds them for Q(√d).

In Q(i) the norm of a + bi is a² + b², which is why a prime p ≡ 1 mod 4 is a sum of two squares: it stops being prime in Z[i] and splits as (a + bi)(a − bi).

Embeddings

A field element is an abstract polynomial in α. toAlgebraic() turns it into an actual number by substituting a chosen root of m, the embedding. Q(√2) uses the positive root, Q(i) the root with positive imaginary part, and you can pick any root by index when making a field.

A field object

Every NumberField is also a plain field object { zero, one, add, sub, mul, div, neg, sign }, the interface that @ratmath/linalg's field-generic algorithms (Gaussian elimination, determinants, inverses) run on. So a matrix over Q(√2) is solved with the same code as one over Q.

In code

import { NumberField } from "@ratmath/algebraic";
const K = NumberField.quadratic(2);   // Q(√2)
const a = K.of([1, 1]);               // 1 + √2
a.inv().toString();                   // "−1 + √2"
a.pow(5).toString();                  // "41 + 29√2"
a.norm().toString();                  // "-1"
a.trace().toString();                 // "2"
a.toAlgebraic().toString(20);         // "2.41421356237309504880…"

const G = NumberField.gaussian();     // Q(i)
G.of([1, 2]).mul(G.of([1, 2])).toString();  // "−3 + 4i"
const C = new NumberField([-2, 0, 0, 1], { name: "∛2" });
C.gen.pow(3).toRational().toString(); // "2"
