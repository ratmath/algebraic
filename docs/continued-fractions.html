Continued fractions, Pell and units

Every real number x is a₀ + 1/(a₁ + 1/(a₂ + …)) with whole numbers aₖ, written [a₀; a₁, a₂, …]. Rationals stop, quadratic irrationals repeat forever, and the cut-off fractions are the best rational approximations there are. This is the Stern–Brocot tree read as a path.

Exact terms for any algebraic number

For an algebraic x, the root of p in an interval, the next term is t = ⌊x⌋: shrink the interval until it lies between two integers. Then x = t + 1/y, and y is a root of

q(y) = yᵈ · p(t + 1/y)

(shift p by t, reverse its coefficients) in the interval mapped by y = 1/(x − t). No digit of x is ever approximated, so every term is right. ∛2 = [1; 3, 1, 5, 1, 1, 4, 1, 1, 8, 1, 14, 1, 10, 2, 1, 4, 12, …] shows no pattern; nobody knows whether its terms are bounded.

Terms and convergents

Each convergent p/q is closer to x than any fraction with a smaller denominator, and |x − p/q| < 1/q². A large next term means an unusually good convergent: π's 355/113 comes right before the term 292.

Quadratic irrationals repeat

Lagrange's theorem: the expansion of x is eventually periodic exactly when x is a quadratic irrational. Written as x = (P + √D)/Q with Q dividing D − P², each step is

a = ⌊(P + √D)/Q⌋, P′ = aQ − P, Q′ = (D − P′²)/Q

all in integers. Only finitely many pairs (P, Q) can occur, so one repeats, and the period is read off exactly.

Pell's equation

x² − D·y² = 1 (D not a square) always has solutions, and the smallest comes from the period of √D: if the period has length L, the convergent p/q just before the end of the first period gives p² − Dq² = (−1)^L. For odd L that solves x² − Dy² = −1, and going around a second period solves the +1 equation. D = 61 is Fermat's famous challenge: the smallest x is 1 766 319 049.

Fundamental units

In the ring of integers of Q(√d) (d > 1 square-free) the units, the elements with norm ±1, are ±εⁿ for a single fundamental unit ε > 1 (Dirichlet). With ω = √d, or (1 + √d)/2 when d ≡ 1 mod 4, shift ω by an integer so that it is reduced (θ > 1 and −1 < θ̄ < 0). Its expansion is then purely periodic, and the product of the complete quotients over one period is ε. That is how 2143295 + 221064√94 appears in a few steps.

In code

import { continuedFraction, convergents, periodicContinuedFraction, fromContinuedFraction, pell, fundamentalUnit, nthRoot, sqrt, fromRational } from "@ratmath/algebraic";
continuedFraction(nthRoot(fromRational(2), 3), 8);   // [1n, 3n, 1n, 5n, 1n, 1n, 4n, 1n]
convergents([1, 2, 2, 2]).map(String);               // ["1", "3/2", "7/5", "17/12"]
periodicContinuedFraction(sqrt(fromRational(7)));    // { preperiod: [2n], period: [1n, 1n, 1n, 4n] }
fromContinuedFraction([1], [2]);                     // √2, exactly
pell(61);              // { x: 1766319049n, y: 226153980n, negative: { x: 29718n, y: 3805n } }
fundamentalUnit(94);   // { unit: 2143295 + 221064√94 (a NumberField element), norm: 1 }
