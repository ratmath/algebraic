Polynomials

Galois groups

The roots of an irreducible polynomial can be shuffled in some ways that keep every polynomial relation among them true. Those shuffles form the Galois group. It decides whether the roots can be written with radicals: x⁵ − x − 1 has group S₅ and cannot, x⁵ − 2 has group F₂₀ and its roots are ⁵√2 times fifth roots of unity.

Degrees 2 and 3

A quadratic's group swaps its two roots: C₂. For a cubic the group is either all six permutations S₃ or just the three rotations A₃ = C₃. The test is the discriminant Δ = Π(αᵢ − αⱼ)²: its square root Π(αᵢ − αⱼ) changes sign under odd permutations, so it is rational exactly when the group has only even ones. x³ − 3x + 1 has Δ = 81 = 9², group C₃.

Degree 4

The resolvent cubic of x⁴ + bx³ + cx² + dx + e has roots α₁α₂ + α₃α₄, α₁α₃ + α₂α₄, α₁α₄ + α₂α₃; its coefficients are

y³ − c·y² + (bd − 4e)·y − (b²e − 4ce + d²)

Each transitive group of degree 4 leaves a different number of those three values fixed:

Resolvent cubicΔ square?GroupOrder
irreduciblenoS₄24
irreducibleyesA₄12
three rational rootsyesV₄ = C₂ × C₂4
one rational root rnoD₄ or C₄8 or 4

The last case is settled by the Kappe–Warren test: the group is C₄ exactly when x² − rx + e and x² + bx + (c − r) both split over Q(√Δ), that is, each has a discriminant that is 0, a square, or a square times Δ.

Degree 5, through certified resolvents

The transitive groups of degree 5 are C₅ ⊂ D₅ ⊂ F₂₀ ⊂ S₅ and A₅ ⊂ S₅. The first three are exactly the solvable ones. The test for "inside F₂₀" uses a quantity that F₂₀ leaves alone but other permutations move: label the five roots as corners of a pentagon and let

θ = (Σ_(pentagon edges) αᵢαⱼ − Σ_(pentagram edges) αᵢαⱼ)²

There are six ways to draw the pentagon, giving six values θ₁ … θ₆ and the sextic resolvent Π(y − θₖ). The group lies in a copy of F₂₀ exactly when that sextic has a rational root (once it is square-free). Then the discriminant separates F₂₀ from D₅, and a second resolvent of degree 4, built from Σ αᵢ²αᵢ₊₁ around the oriented pentagon, separates D₅ from C₅.

The resolvents have integer coefficients (they are symmetric functions of the roots of a monic integer polynomial), but no formula is needed. The library computes them from certified boxes around the five roots with exact interval arithmetic, refining until each coefficient's interval contains exactly one integer. So the result is proven, not estimated. If a resolvent comes out with a repeated root, the roots are first moved by a Tschirnhaus transformation y = x² + kx, which keeps the group.

In code

import { galoisGroup } from "@ratmath/algebraic";
galoisGroup([-2, 0, 0, 0, 1]);
// { degree: 4, name: "D4", order: 8, label: "4T3", solvable: true,
//   discriminant: Rational(-2048), discriminantIsSquare: false, resolventCubic: [...] }
galoisGroup([-1, -1, 0, 0, 0, 1]).name;   // "S5", not solvable by radicals
galoisGroup([-1, 0, 0, 0, 0, 1]);         // reducible: { reducible: true, factors: [...] }

Labels follow the transitive-group numbering nTk. Degree 6 and above are not covered yet.
